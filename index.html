How to lay out a CSV file

Put one question on each row, in this column order:

question, option_a, option_b, option_c, option_d, answer, explanation

The answer can be a letter (A to D), a number (1 to 4) or the answer text itself. The explanation is optional. With a header row you can use 2 to 6 option columns in any order.

Which PDFs work

A question paper with numbered questions and lettered options, like this:

1. What is 2 + 2?
A. 3
B. 4
C. 5
Answer: B

An answer line under each question, or an answer key at the end, is picked up. If the PDF has no answers, you mark them in the editor after importing. Scanned pages are read with OCR, which is slower and can misread letters. The PDF is read on your device and is not uploaded.
